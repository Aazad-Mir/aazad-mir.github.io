# Aazad Mir Portfolio Website

This repository contains the final AI-tech bilingual portfolio website for Aazad Mir.

## Main Features

- Dark AI / technical portfolio design
- English and Arabic language switcher
- Animated AI particle background
- Typewriter terminal animation
- Hiring-manager highlights
- AI Recruiter View section
- Ctrl + K / Cmd + K command palette
- CV download button
- LinkedIn button
- WhatsApp and email buttons
- Save contact vCard
- Mobile responsive layout
- GitHub Pages ready

## Important Files

- `index.html` — main website content
- `style.css` — design and responsive layout
- `script.js` — animations, language switcher, command palette
- `assets/Aazad_Mir_CV.pdf` — CV file
- `assets/Aazad_Mir_Contact.vcf` — contact card
- `images/aazad-profile.jpg` — profile photo
- `images/linkedin-banner.jpg` — banner image
- `WHERE_TO_CHANGE_CONTENT.md` — editing guide

## GitHub Pages

This site is ready to publish from the `main` branch and `/root` folder.
